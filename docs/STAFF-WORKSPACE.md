# Staff workspace

The main menu contains six sections:

| Section | Main staff question |
| --- | --- |
| Overview | Where should staff focus next? |
| Programme Analysis | Which programme domains and programmes reach seniors and sustain participation? |
| Participation Insights | Which participant groups attend, return or have participation gaps? |
| Client Engagement | Which registered clients need outreach or follow-up? |
| Participant Needs | What recorded needs should inform programme delivery? |
| SPPB Assessments | How do recorded physical performance scores relate to participation and participant profiles? |

Programme Analysis starts with the combined Programme Domain analysis. Expand **Browse all programmes and detailed comparisons** for the detailed programme list. These details load when opened. Viewers retain their permitted aggregate programme list.

SPPB starts with its overview. Recorded source scores and linked comparisons remain descriptive; they do not establish that attendance causes score changes.

Use **Data & settings** for imports, data management, reporting definitions and centre administration. Available choices follow existing access permissions. Use the header **Export** for reports.

The separate Planning, Custom Analysis, Operations and duplicate needs pages are removed from the menu. Legacy in-app navigation resolves to the relevant retained section. Existing records, plans, targets, source values and backend interfaces are preserved. Per-programme details retain the original classification audit; the separate raw classification matrix is removed from the staff analysis page.

No new database migration is required. Existing centre and SPPB setup requirements still apply.
