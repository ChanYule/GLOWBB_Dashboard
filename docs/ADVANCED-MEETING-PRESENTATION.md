# Advanced presentation and chart controls

Open **Compare reporting periods** on Overview to compare unique seniors, attendances, sessions and programmes. The panel offers a previous equivalent period when the dashboard has calculated it, completed calendar month and quarter, the same dates last year, and a custom date range. Explicit comparison queries reuse the selected centre and dashboard filters. The panel validates dates against recorded attendance coverage and shows absolute change when the previous value is zero.

Shared ranking charts offer **Expand chart** and a table alternative. Shareable Programme Domain and meeting rankings offer PNG or SVG download. The expanded dialog stays on the selected chart and uses its active number or percentage setting. Downloads are rendered from the displayed chart data in the browser at 2x resolution for PNG, with a white background. Programme Domain and ranking charts pass their date context into the export. Protected SPPB comparisons continue to use their existing report controls. Large and Extra Large display settings now also affect shared KPI figures, chart titles and analytical tables.

For SEEN Nanyang, choose **Present**, then open **My Meeting Layouts**. Select a template or create a layout, name it, add or remove sections, move them into order, and save it on the current device. Selecting a preset for the previous completed calendar month or quarter resolves the actual dates when you choose **Present now**. Under **Presentation tools**, choose **Prepare selected sections for PDF**, then use **Print / Save as PDF**. Use Left, Right, Home and End to navigate and F to toggle full screen. Layouts store configuration only.

The SEEN Nanyang meeting endpoint checks the granted centre and staff role before reading data. It reads a consistent centre state inside a single read transaction and builds the overview, Programme Domains and protected briefing together. The client holds this aggregate package until staff refresh. PostgreSQL revision checks on browser focus or visibility changes can show a new-data notice without replacing the meeting figures. A production cache miss still loads the centre planning snapshot once. The endpoint reuses the existing bounded aggregate cache and migration 008 revision mechanism.

The prior meeting view loaded two analytical endpoints on opening and another when staff first opened the protected briefing. The synthetic Chromium check observed one meeting endpoint call on opening and zero additional requests when navigating between loaded sections. Display settings also generated zero additional requests. This is an API request comparison. Production database transfer and wall-clock improvements remain unmeasured.

The local browser test used synthetic SEEN Nanyang figures, captured light and dark views, exercised chart expansion, downloaded a high-resolution PNG, and generated a PDF after assembling eight selected sections. Captures cover 1366 x 768, 1920 x 1080, 2560 x 1440, tablet and mobile viewports. Additional verification is needed for PDF pagination across every data volume and the native full-screen permission flow on staff devices.

Remaining scope includes per-layout population, colour and chart overrides, account-synced layouts, an SPPB assessment template, selected period comparisons in specialist reports, a separate findings editing workflow, chart expansion for non-ranking visuals, and SQL-side aggregation of the meeting's cold read. The existing domain findings are used as the meeting findings. The checkout has no new migration for this release. Apply the earlier migration 008 if still pending, then build and deploy to the existing Render service.
